# Geist

Unmodified Latin WOFF2 fonts served by Google Fonts:

- [Geist.woff2](https://fonts.gstatic.com/s/geist/v5/gyByhwUxId8gMEwcGFWNOITd.woff2)

The [SIL Open Font License 1.1](https://github.com/google/fonts/blob/main/ofl/geist/OFL.txt)
is included in `LICENSE.txt`.

The site uses `next/font/local` to preserve its font family and CSS variable
without downloading fonts during builds. Characters outside the bundled Latin
subset use the theme fallback font stacks.

These files match the original `next/font/google` Chrome 104 font responses.
Separate face declarations retain the original requested weights.
